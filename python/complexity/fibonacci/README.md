# フィボナッチ数列とは
F(n+1) = F(n) + F(n-1)を満たす数列。  
つまり、前の二つの数を足すと次の数になる数列のこと。  
非効率な方法(O(2^n))から効率的な方法(O(logn))まで比較していく。　　

## 単純再帰 O(2^n)
単純再帰は文字通り単純に再帰的に求めていく。　　
O(2^n)であり今回触れる方法の中で最も非効率である。　　

## メモ化再帰(Top down DP) O(n)
重複計算を防ぐために、一度計算した答えを辞書や配列に記録しておく方法。　　
処理時間はO(n)と速くなるが、メモ用のメモリを消費する。つまり空間計算量がO(n)となる。　　

## 動的計画法(Bottom up DP) O(n)
下から順番に足していくアプローチ。フィボナッチ数列の性質であるF(n+1)を求めるためには、前のF(n), F(n-1)のみ記録しておけば良いという性質を利用し、空間計算量を減らしたアプローチ。　　
空間計算量はO(1)  

## 行列累乗法 O(logn)
フィボナッチ数列を行列として表し、さらに繰り返し二乗法を用いて効率的に行列計算をすることで劇的に計算量を減らすアプローチ。
